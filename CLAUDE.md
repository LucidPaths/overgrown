# overgrown — instructions for every agent

An open-source, browser-first, top-down sandbox hack-and-slash RPG. All art and audio are generated by code in this repo. It's **not** an MMO, not a survival game, and not a roguelite. See `docs/gdd/00-overview.md`.

## Layout

```
sim/           @overgrown/sim — pure TS simulation. Sees NO browser APIs (lib ES2022, types []). Runs in a Web Worker and in Node.
client/        @overgrown/client — Vite + PixiJS app (renderer, input, UI, worker adapter, net)
tools/art/     Python asset pipeline → client/public/generated/ (gitignored build output)
contracts/     cross-language fixtures (e.g. RNG test vectors) shared by TS and Python tests
scripts/       dev tools run with node (check-page.mjs: headless page check)
services/      (later) tiny signaling service
.claude/skills/ discipline skills copied from LucidPaths/claude.md-workflow (goal-loop, adversarial-review, …); docs/agents/ wins where they differ
docs/          gdd/, agents/, specs/, e2e/, PRINCIPLE_LATTICE.md
```

No barrel files: import modules by path (`@overgrown/sim/version`), never through an `index.ts`.

## Commands

Activate a Python 3.13 venv with `tools/art/requirements-dev.txt` installed first. Convention: `.venv/` at the repo root (gitignored): `python3.13 -m venv .venv && .venv/bin/pip install -r tools/art/requirements-dev.txt`, then `source .venv/bin/activate`.

```
npm ci              install (lockfile committed)
npm run check       typecheck sim + client, eslint, ruff check, ruff format --check
npm test            vitest (TS) + pytest (tools/art)
npm run build       art pipeline, then client production build → client/dist/
npm run dev         Vite dev server
node scripts/check-page.mjs <url> [shot.png] [waitMs]   headless page check (canvas info, console errors; exit 1 on errors)
```

CI (`.github/workflows/ci.yml`) runs check, test and build on every push to main and every PR.

## Hard rules

- **No claims without evidence:** write "Ran X → Y" from the same response. "Should work" is forbidden.
- **Determinism:** seeded paths (worldgen, RNG, asset pipeline) produce identical output for identical input. Never use `Math.random()` or wall-clock time in seeded code.
- **Everything is ours:** never commit images or audio that the pipeline didn't generate. No downloaded or AI-generated assets.
- **Sim/renderer boundary:** the renderer only reads snapshots; it never mutates game state.
- **One rule set:** players and NPCs use the same systems. No player-only code paths in the sim.
- **Tests guard real breakage only.** No ceremonial tests. Milestone E2E covers the rest.
- **Mention it, don't do it:** out-of-scope findings go in your report, not your diff.
- **Never commit to `main` directly**, except the orchestrator's GDD ticks and WORKING_STATE updates.
- **Three failed fixes → stop and escalate.**

## Project traps

Add each one here as it's discovered.

- **TypeScript is pinned to 6.x** because typescript-eslint doesn't support TS 7 yet (Oct 2026). Don't bump TS alone; bump both together.
- **EntityId generations wrap at 4096.** After 4096 destroy/create cycles of one slot, an old ID becomes valid again. Never store EntityIds long-term (saves, network, quest targets) without a separate stable identity.
- **RNG inputs must be safe integers** (|v| ≤ 2^53−1). Both languages reject anything else, so they can't diverge.
- **`npm run dev` builds the art first.** Pass Vite args after `--` (`npm run dev -- --port 4183`).
- **Debug movers are temporary scaffolding** (`sim/src/debug-movers.ts`, `debug/*` frames). Remove them when real entities land in M1/M2.
- **Cloud sessions (claude.ai/code):** `gh` has no valid token there and the git proxy refuses branch deletion. Use the GitHub connector tools for PRs, comments and merges; Lucid deletes branches in the GitHub UI. Locally, `gh` works normally.
- **Engine-dependent float math.** `Math.sin/cos/pow/exp/log`, `**` and friends can differ between JS engines; only `+ - * /` (and `sqrt`) are exactly rounded. Seeded sim code must avoid them. ESLint enforces this in `sim/src/world/`; elsewhere it's on you.
