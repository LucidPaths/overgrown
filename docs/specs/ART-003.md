## Desired result
Generators draw pixel art from a small set of deterministic, crisp (no anti-aliasing) primitives on numpy RGBA arrays. Shading uses palette ramps with ordered dithering, so every sprite stays inside its palettes. The debug generator is rewritten on top of these primitives, as their first real consumer.

## Locked design
`tools/art/lib/draw.py`. Images are `numpy.ndarray` of shape (H, W, 4), dtype uint8. Colors are RGBA tuples from palettes. **Alpha is binary (0 or 255) everywhere**, which is the pixel-art rule.

```
canvas(w, h) -> ndarray                                 # fully transparent
rect(img, x, y, w, h, color) -> None                    # filled, clipped to bounds
line(img, x0, y0, x1, y1, color) -> None                # Bresenham, endpoints inclusive, clipped
ellipse_mask(w, h, cx, cy, rx, ry) -> ndarray[bool]     # pixel (x,y) is inside iff ((x+0.5-cx)/rx)^2 + ((y+0.5-cy)/ry)^2 <= 1
fill_mask(img, mask, color) -> None
outline(img, color, diagonal=False) -> None             # transparent pixels 4-adjacent (8 if diagonal) to opaque ones become color; computed from the pre-outline image
bayer4(x, y) -> float                                   # standard 4x4 Bayer threshold in [0,1): (M[y%4][x%4] + 0.5) / 16
dither(img, mask, color_a, color_b, level) -> None      # inside mask: color_b where bayer4(x,y) < level, else color_a; level in [0,1]
shade_sphere(img, mask, ramp, light=(-0.6, -0.6, 0.53)) -> None
    # treat the mask's bounding ellipse as a hemisphere; normal from normalized ellipse coords
    # (nz = sqrt(max(0, 1 - nx² - ny²))); lambert = clamp(dot(n, normalize(light)), 0, 1);
    # v = lambert * (len(ramp) - 1); pick ramp[floor(v)] or ramp[floor(v)+1] by dithering with
    # threshold frac(v) against bayer4 → only ramp colors appear
paste(dst, src, x, y) -> None                           # copy src where src alpha == 255; clipped
to_image(arr) -> PIL.Image (RGBA)                       # asserts binary alpha before converting
```
No floating-point colors anywhere in the output, no randomness inside draw.py (callers pass rng-derived values in), and no Pillow `ImageDraw` (it anti-aliases some shapes; we own every pixel).

`gen/debug.py` rewritten on draw.py:
- `debug/checker16`: `rect` calls, using the **first and last** shade of `meadow.grass` (the critic noted index [3] would crash on a valid 3-shade ramp).
- `debug/mover32`: one of the pop element ramps (`fire`, `frost`, `stone`, `storm`, `life`, `shadow`) picked with `ctx.rng("mover")`; `ellipse_mask` radius 12 centered; `shade_sphere` with that ramp; `outline` with the ramp's darkest shade. The output must stay deterministic.

## Acceptance criteria
- AC1 Geometry is exact — proven by tests:
  - `outline` of a single opaque pixel at the center of 5×5 gives exactly 4 outline pixels (8 with diagonal=True)
  - `ellipse_mask` is mirror-symmetric on both axes for an even-sized centered ellipse
  - `line` from (0,0) to (4,2) hits exactly the Bresenham pixel set
- AC2 Dithering is exact — proven by tests: level 0 → all color_a, level 1 → all color_b, level 0.5 on a 4×4 area → exactly 8 of each.
- AC3 Shading stays in palette and is lit correctly — proven by test: after `shade_sphere`, every opaque pixel's color is in the ramp, and the mean luminance of the top-left quadrant > the bottom-right quadrant.
- AC4 Binary alpha is enforced — proven by test: `to_image` on an array containing alpha 128 raises.
- AC5 Still deterministic and green — two builds into temp dirs `cmp` identical; `npm run check && npm test && npm run build` → exit 0.
- AC6 It looks like pixel art — proven by: view the built `client/public/generated/core.png` (scaled up in a throwaway copy if needed) and describe the mover in one line in the report.

## Tests
`tools/art/tests/test_draw.py`: AC1–AC4. These guard off-by-one geometry, broken dithering and colors leaking outside the palette, all of which would silently degrade every future sprite. Show each fails when broken, then revert.
