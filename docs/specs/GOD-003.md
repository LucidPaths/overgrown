## Locked design
1. **`game/src/core/rng.gd`**, `class_name OgRng`.
   - **Static functions:** `fmix32(x)`, `mix_seed_part(h, part)`, `derive_seed(seed, parts: Array)` and `hash_string(s)`.
   - **Instance API:** `_init(seed)`, `next_u32()`, `next_float()` and `int_range(lo, hi)`.
   - **Representation:** GDScript `int` is a signed 64-bit integer. Represent every u32 as an `int` in `0..0xFFFFFFFF` and mask with `& 0xFFFFFFFF` after every operation that can leave that range.
   - **`imul32(a, b)`:** never form a product that can exceed 2^63. A plain `a * b` of two u32 values can reach 2^64 and overflow. Split one operand into 16-bit halves: `((a * (b & 0xFFFF)) + (((a * (b >> 16)) & 0xFFFF) << 16)) & 0xFFFFFFFF`. Prove it in a test against the vectors and against products near 0xFFFFFFFF × 0xFFFFFFFF.
   - **Unsigned right shift (`>>>`):** for a masked u32, `>>` is equivalent.
   - **`rotl32`:** shift left, mask, OR in the shift right, mask again.
   - **Negative `parts` in `derive_seed`:** `-1` becomes 0xFFFFFFFF, exactly like `part >>> 0` in TS.
2. **Validation errors.** GDScript has no exceptions, so mirror the TS error *conditions* this way: call `push_error(...)` and return a sentinel, `-1` for functions that return u32. A seed outside 0..2^32-1, an out-of-range part, `lo > hi` or `hi - lo >= 2^32` must never silently produce a value. The tests check that each one is rejected.
3. **`hash_string(s)`:** FNV-1a 32 over the UTF-8 bytes of `s` (`s.to_utf8_buffer()`), then `fmix32`. Must match the `hashString` vectors, including the emoji.
4. **`game/tests/test_rng.gd`:**
   - Reads `contracts/rng-vectors.json` from `ProjectSettings.globalize_path("res://").path_join("../contracts/rng-vectors.json")`. A missing file is a FAIL, not a skip.
   - Asserts every vector in every section.
   - Asserts the `imul32` edge products. Compute their expected values independently; the test comments show how.
   - Asserts the validation rejections.
