## Locked design

**Dependency:** `playwright-core` at exact version `1.56.1` in the root `package.json` `devDependencies` (keep alphabetical order), lockfile updated with `npm install`. 1.56.1 is the version whose bundled browser revision is Chromium 1194, which matches the preinstalled browsers in the cloud container (`PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers`). Elsewhere, run `npx playwright-core install chromium-headless-shell` once. Do not add `playwright` or `@playwright/test`.

**CLI:** `node scripts/check-page.mjs <url> [screenshot.png] [waitMs]`
- `url` is required. `screenshot.png` is optional. Pass `-` to skip the screenshot when you need to pass `waitMs`. `waitMs` is an integer ≥ 0, default `1000`. It is how long to wait after the `load` event before collecting results, so the sim and renderer get a few frames.
- Viewport 1280×720.
- Usage errors (missing url, non-integer or negative waitMs, more than 3 args) → print a one-line usage message to stderr and exit **2**.

**Collected errors** (each one a string, in the order they happened):
- every `console` message of type `error` → `"console: <text>"`
- every uncaught page exception (`pageerror`) → `"pageerror: <message>"`
- navigation failure (thrown by `page.goto`) or a main-document HTTP status ≥ 400 → `"navigation: <reason or status>"`. On navigation failure, skip the wait and the screenshot, but still print the JSON and exit 1.

**Output:** exactly one JSON object on stdout (pretty-printed, 2-space indent), shaped like this:
```json
{
  "url": "http://localhost:4173/",
  "canvas": true,
  "canvases": [{ "width": 1280, "height": 720, "cssWidth": 1280, "cssHeight": 720 }],
  "errors": [],
  "screenshot": "/tmp/x.png"
}
```
- `canvas` is `canvases.length > 0`. `width`/`height` are the canvas backing-store size. `cssWidth`/`cssHeight` come from `getBoundingClientRect()`, rounded to integers.
- `screenshot` is the absolute path written, or `null`.

**Exit code:** 0 if `errors` is empty, 1 otherwise. A missing canvas is reported in the JSON but is not an error by itself. The browser is always closed (`finally`) before exiting. If the browser itself fails to launch, let the error propagate: Node prints the stack and exits non-zero. Don't catch it and don't rewrite its message, because Playwright's own message tells you how to install the browser.

**Lint:** `scripts/**/*.mjs` runs on Node. Add one config block to `eslint.config.js` that gives these files the Node globals they use, declared inline (for example `process: "readonly"`, `console: "readonly"`). No `globals` package, no other new dependency.

**Role files.** Add one short reference each and change nothing else in them:
- `docs/agents/E2E.md` step 2: boot and console checks use `node scripts/check-page.mjs`. Scripted input still means writing a Playwright script with `playwright-core`.
- `docs/agents/WORKER.md`: for tasks that change what the page shows, the spec's verification includes `node scripts/check-page.mjs` against `vite preview`.
- `docs/agents/CRITIC.md`: the critic re-runs any `check-page.mjs` command in the spec's verification.
- `docs/agents/SPEC_TEMPLATE.md` (the "Verification commands" section of the template): page-level checks use `npm -w @overgrown/client run preview -- --port <port> &` then `node scripts/check-page.mjs http://localhost:<port>/ [shot.png] [waitMs]`.

Delegated micro-decisions:
- Chromium launch flags needed for WebGL in headless mode (for example a SwiftShader/ANGLE flag). Pick the minimal set that makes AC2 pass, and name them in your report.
- The exact wording of the usage message and of the role-file sentences.

## Acceptance criteria
- AC1 `playwright-core` 1.56.1 is a root devDependency and `npm ci` installs it — proven by: `node -e "console.log(require('playwright-core/package.json').version)"` → `1.56.1`
- AC2 The built client boots cleanly — proven by: `npm run build`, then `npm -w @overgrown/client run preview -- --port 4190 &`, then `node scripts/check-page.mjs http://localhost:4190/ /tmp/ovr006.png 2000` → exit 0, `"canvas": true`, `"errors": []`, the PNG exists, and the screenshot shows sprites (not a blank page).
- AC3 Console errors fail the check — proven by: `node scripts/check-page.mjs "data:text/html,<canvas></canvas><script>console.error('boom')</script>"` → exit 1, `errors` contains `"console: boom"`.
- AC4 Uncaught exceptions fail the check — proven by: `node scripts/check-page.mjs "data:text/html,<script>throw new Error('kaboom')</script>"` → exit 1, `errors` has an entry that starts with `"pageerror:"` and contains `kaboom`.
- AC5 Navigation failure fails the check — proven by: `node scripts/check-page.mjs http://localhost:1/` → exit 1, `errors` has an entry that starts with `"navigation:"`, `"screenshot": null`.
- AC6 Usage errors exit 2 — proven by: `node scripts/check-page.mjs; echo $?` → `2`, and `node scripts/check-page.mjs http://x/ - abc; echo $?` → `2`.
- AC7 The four role files reference `scripts/check-page.mjs` — proven by: `grep -l "check-page.mjs" docs/agents/*.md` lists E2E.md, WORKER.md, CRITIC.md and SPEC_TEMPLATE.md.
- AC8 Typecheck, lint, tests and build are clean — proven by: `npm run check && npm test && npm run build`
