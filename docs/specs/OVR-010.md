# OVR-010: Retire the TypeScript, Pixi and Python packages

Plan: `docs/overhaul/PLAN.md` ("What we keep, port and retire": `client/`, `tools/art/`, `sim/`, `scripts/` are **retired** once the G0 ports are proven; they stay in git history) and `docs/gdd/00-overview.md` OVR-010.
Milestone: G0   Depends on: GOD-003 (#38) and GOD-004 (#39), both merged and proven bit for bit against the TS and Python output.
Model: sonnet. Mostly deletion plus doc bookkeeping; the judgement is in what stays.
Branch: ovr-010-retire-ts

## Desired result
The repo is a Godot project with docs. A new agent no longer sees two stacks, CI runs no npm or Python jobs, and the broken Pages deploy workflow is gone. Everything the old stack proved stays reachable: in git history, at a commit named in CLAUDE.md.

## Locked design
1. **Reference commit.** Before deleting anything, note the current `origin/main` sha. CLAUDE.md gets one line under Layout:

   > "The TypeScript/Pixi/Python stack (M0–M1) was retired in OVR-010. Read it with `git show <sha>:sim/src/…` (or `client/`, `tools/art/`, `scripts/`)."

   Agents porting more rules (GOD-006 and later) use this.
2. **Delete:**
   - `sim/`, `client/`, `tools/art/`, `scripts/`;
   - the root `package.json`, `package-lock.json`, `tsconfig.base.json`, `eslint.config.js`;
   - `.github/workflows/deploy.yml`;
   - the `ci` (npm and Python) job in `ci.yml`, keeping the `godot` job and its credits step.
   - Also delete any root config that only served those packages: `.nvmrc`, ruff or pytest config, `.prettierrc` and the like, if present. Check `.gitignore` too: remove entries for deleted outputs (`client/public/generated/`, `node_modules/`, `.venv/` and so on) only if nothing else needs them; keep entries that `game/` needs.
3. **Contracts.**
   - Keep `contracts/rng-vectors.json` and `contracts/worldgen-vectors.json`. GDScript (`game/tests/test_rng.gd`, `test_worldgen.gd`) still checks them, and they are the frozen record of the old output.
   - Delete `contracts/actor-anims.json` and `contracts/tile-frames.json` (pixel-sprite contracts with no Godot consumer). First grep `game/` to confirm nothing reads them.
   - Add a short `contracts/README.md`: what each remaining file is, who checks it, and that the TS and Python generators are gone. To regenerate them, use the reference commit, or treat them as frozen.
4. **Docs.**
   - **CLAUDE.md:**
     - remove the retired Layout lines (keep the reference-commit line);
     - remove the npm and venv commands and the "Activate a Python 3.13 venv" paragraph;
     - remove the contract rows whose every source of truth is deleted (Atlas, Kind → frame, Render resolution, Perf measuring, Host input merge, Touch control geometry, Actor rows, Ground tile frames, Chunk streaming (TS), Ground rendering, and so on);
     - rewrite the rows that have a Godot implementation so they name only the GDScript sources plus the contract fixture;
     - remove TS- and Python-only traps;
     - keep every Godot row and trap exactly as it is.
   - **README.md:** drop the "old TypeScript code" note and the npm develop steps.
   - **`docs/agents/*.md`:** remove the "(TS, until OVR-010)" lines.
   - **`docs/gdd/01-tech.md` and `00-overview.md`:** retired-package prose becomes one history sentence. Tick nothing; the orchestrator ticks OVR-010.
   - **`docs/perf.md`:** add a one-line header that it describes the retired browser build (history). Don't rewrite it.
   - **`docs/art/DIRECTION.md` and `RESEARCH.md`:** the same one-line history header.
   - Leave `docs/e2e/`, `docs/specs/` and `WORKING_STATE.md` untouched: they're history and orchestrator files.
   - The GDD's ticked TS-era tasks stay ticked (delivered history).
5. **Nothing in `game/` changes.**

## Acceptance criteria
- **AC1** `bash tools/godot/test.sh` → all pass. `bash tools/check-credits.sh` → ok. `bash tools/godot/export.sh` → both builds.
- **AC2** `ci.yml` and `release.yml` parse as YAML. `ci.yml` has only the `godot` job.
- **AC3** `grep -rnE "sim/|client/|tools/art|scripts/|npm |vitest|pytest|ruff|Pixi|vite" CLAUDE.md README.md docs/agents docs/gdd contracts .github` → every remaining hit is the reference-commit line, a history sentence, or a ticked or struck task. Paste the output with a one-word verdict per line.
- **AC4** `grep -rn "actor-anims\|tile-frames" game/` → no hits, so deleting those contracts is safe.
- **AC5** `git ls-files | wc -l` before and after, and `git ls-files | cut -d/ -f1 | sort | uniq -c` after. Report both.
