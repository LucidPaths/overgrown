## Desired result
`generateChunk(seed, cx, cy)` returns both a `tiles` layer and a new `biomes` layer (Grassland, Forest, River, Mountain, Ocean), classified from separate seeded elevation, moisture, temperature and river fields sampled at world tile coordinates. Oceans have depth bands and sand coasts, rivers are mostly shallow with deep cores only in wide stretches and seeded fords through them, and mountains have stone with gapped cliff lines on steep slopes. Pinned digests prove determinism, the seam tests still prove seamlessness, and one statistical test catches a broken biome mix.

## Locked design

### Shared rules (M1 contract, verbatim)
- y-down; `tile = Math.floor(px / TILE_PX)`, `chunk = Math.floor(tile / CHUNK_TILES)`; local index `ly * CHUNK_TILES + lx`; world tile `tx = cx * CHUNK_TILES + lx`, `ty = cy * CHUNK_TILES + ly`.
- `ChunkData = { cx, cy, tiles: Uint8Array(1024) }`; WLD-002 adds `biomes: Uint8Array(1024)` and a `Biome` const (`Grassland 0, Forest 1, River 2, Mountain 3, Ocean 4`) in `sim/src/world/biome.ts`.
- Pure functions of the inputs. Only integer hashing (`Math.imul`, bit ops), `+ - * /`, `Math.floor`, `Math.abs`, `Math.min`, `Math.max`. **Never** `Math.sin/cos/pow/exp/log/random`, `**`, `Date`. The ESLint block from WLD-001 already covers `sim/src/world/**`; do not touch `eslint.config.js`.
- Every field is sampled at **world** tile coordinates, including the neighbour samples used for slopes. That keeps chunk borders seamless by construction.

### Field-by-field design (what each piece is for)
| Piece | Source | Used for |
|---|---|---|
| elevation | fBm `"elevation"` | Ocean below, Mountain above; ocean depth bands; cliff slope and terraces |
| moisture | fBm `"moisture"` | Forest vs Grassland |
| temperature | fBm `"temperature"` | **reserved**: computed and stored in the sample, used by nothing until tundra/desert/snow biomes exist |
| river | fBm `"river"`, ridged: `abs(2·n − 1)` | river band; distance to the band centre in tiles = ridge / slope |
| river-width | fBm `"river-width"` | half-width of the river water in tiles (1–6) |
| detail | fBm `"detail"` | Dirt patches (Grassland, Forest) and cliff gaps (Mountain) |
| ford-x / ford-y | `deriveSeed` sub-seeds | seeded ford stripes that cut deep river water |

### `sim/src/world/biome-map.ts` (new: all sampler code)
```ts
import { deriveSeed, hashString } from "../rng";
import { createFbm, type Field2 } from "./noise";   // same import style as chunk-gen.ts
import { Biome, type BiomeValue } from "./biome";

/** Field octaves in tiles (all tunable). The 256-tile base gives land regions ~7–9 chunks across (OQ-024). */
export const ELEVATION_WAVELENGTHS = [256, 128, 64, 32] as const;
export const MOISTURE_WAVELENGTHS = [256, 128, 64] as const;
export const TEMPERATURE_WAVELENGTHS = [512, 256] as const;
export const RIVER_WAVELENGTHS = [256, 128, 64] as const;
export const RIVER_WIDTH_WAVELENGTHS = [512] as const;
export const DETAIL_WAVELENGTHS = [16, 8] as const;

/** Every seeded input of worldgen for one world seed. Build once per generateChunk call. */
export interface WorldFields {
  elevation: Field2; moisture: Field2; temperature: Field2; river: Field2; riverWidth: Field2; detail: Field2;
  fordSeedX: number; fordSeedY: number;
}
export function createWorldFields(seed: number): WorldFields;

/** One biome sample at a world tile. Pure; temperature is reserved (computed, not yet used). */
export interface BiomeSample {
  elevation: number;      // [0, 1)
  moisture: number;       // [0, 1)
  temperature: number;    // [0, 1), reserved
  riverDist: number;      // approx. tiles from the river band centre; Infinity when not near a river
  riverHalfWidth: number; // river water half-width in tiles at this point; 0 when not near a river
}
export function sampleBiome(f: WorldFields, tx: number, ty: number): BiomeSample;
export function classifyBiome(s: BiomeSample): BiomeValue;
```
Constants (all tunable; keep each as a named module constant, not exported unless listed above):
```
OCEAN_BELOW = 0.38          MOUNTAIN_FROM = 0.62          FOREST_FROM = 0.52
RIVER_NEAR = 0.08           RIVER_HALF_WIDTH_MIN = 1      RIVER_HALF_WIDTH_MAX = 6      RIVER_BANK = 1.5
```
Algorithm (locked, including evaluation order; the golden digests depend on it):
```
field(seed, name, W) = createFbm(deriveSeed(seed, hashString(name)), W)

createWorldFields(seed):
  elevation   = field(seed, "elevation",   ELEVATION_WAVELENGTHS)
  moisture    = field(seed, "moisture",    MOISTURE_WAVELENGTHS)
  temperature = field(seed, "temperature", TEMPERATURE_WAVELENGTHS)
  river       = field(seed, "river",       RIVER_WAVELENGTHS)
  riverWidth  = field(seed, "river-width", RIVER_WIDTH_WAVELENGTHS)
  detail      = field(seed, "detail",      DETAIL_WAVELENGTHS)
  fordSeedX   = deriveSeed(seed, hashString("ford-x"))
  fordSeedY   = deriveSeed(seed, hashString("ford-y"))

sampleBiome(f, tx, ty):
  elevation   = f.elevation(tx, ty)
  moisture    = f.moisture(tx, ty)
  temperature = f.temperature(tx, ty)
  riverDist = Infinity; riverHalfWidth = 0
  ridge = Math.abs(f.river(tx, ty) * 2 - 1)                 # 0 on the band centre line
  if ridge < RIVER_NEAR:                                    # skip the slope work far from rivers (also part of the algorithm)
    slope = Math.max(Math.abs(f.river(tx + 1, ty) - f.river(tx - 1, ty)),
                     Math.abs(f.river(tx, ty + 1) - f.river(tx, ty - 1)))   # = per-tile slope of 2n-1 (max-norm, no sqrt)
    if slope > 0: riverDist = ridge / slope
    riverHalfWidth = RIVER_HALF_WIDTH_MIN + (RIVER_HALF_WIDTH_MAX - RIVER_HALF_WIDTH_MIN) * f.riverWidth(tx, ty)
  return { elevation, moisture, temperature, riverDist, riverHalfWidth }

classifyBiome(s):                                           # checked in this order
  s.elevation <  OCEAN_BELOW                          → Ocean
  s.elevation >= MOUNTAIN_FROM                        → Mountain
  s.riverDist <  s.riverHalfWidth + RIVER_BANK        → River      (rivers stop at coasts and mountains)
  s.moisture  >= FOREST_FROM                          → Forest
  else                                                → Grassland
```
Domain note (put it as a one-line comment in `sampleBiome`/`pickTile`): neighbour samples reach one tile past chunk coordinates, so at the extreme `cx`/`cy` (±2^26) they hit x = −2^31 − 1 or 2^31, one outside `createFbm`'s documented domain. That is harmless here because every wavelength is ≥ 8, so lattice indices stay far inside int32. The golden test pins both extreme corners.

### `sim/src/world/chunk-gen.ts` (rewritten classification)
Remove `createElevation`, `classifyElevation` and `ELEVATION_WAVELENGTHS` (elevation now lives in `biome-map.ts`). `chunk-gen.ts` imports `Biome`/`BiomeValue` from `./biome` and the sampler from `./biome-map`. Keep `generateChunk`'s signature and its input validation exactly as WLD-001 has them.
```ts
export interface ChunkData {
  cx: number; cy: number;
  tiles: Uint8Array<ArrayBuffer>;   // TileValue per tile, length CHUNK_TILES * CHUNK_TILES
  biomes: Uint8Array<ArrayBuffer>;  // BiomeValue per tile, same indexing
}
/** True on a seeded ford stripe: one FORD_WIDTH-tile stripe per FORD_CELL-tile cell, per axis. */
export function isFord(f: WorldFields, tx: number, ty: number): boolean;
/** The ground tile for a biome sample at world tile (tx, ty). */
export function pickTile(f: WorldFields, s: BiomeSample, biome: BiomeValue, tx: number, ty: number): TileValue;
export function generateChunk(seed: number, cx: number, cy: number): ChunkData;
```
Constants (all tunable; named module constants):
```
VERY_DEEP_BELOW = 0.27      DEEP_BELOW = 0.32             SHALLOW_BELOW = 0.355         (ocean bands; Sand from 0.355 to OCEAN_BELOW)
RIVER_DEEP_MIN_HALF_WIDTH = 4                             RIVER_SHALLOW_RIM = 2
FORD_CELL = 64              FORD_WIDTH = 3
CLIFF_TERRACES = 25         CLIFF_SLOPE = 0.002           CLIFF_GAP_BELOW = 0.35
GRASSLAND_DIRT_FROM = 0.68  FOREST_DIRT_FROM = 0.5
```
Algorithm (locked, including evaluation order):
```
inFordStripe(fordSeed, t):
  cell   = Math.floor(t / FORD_CELL)
  offset = Math.floor((deriveSeed(fordSeed, cell) / 4294967296) * (FORD_CELL - FORD_WIDTH + 1))   # 0..FORD_CELL-FORD_WIDTH
  local  = t - cell * FORD_CELL
  return local >= offset && local < offset + FORD_WIDTH

isFord(f, tx, ty) = inFordStripe(f.fordSeedX, tx) || inFordStripe(f.fordSeedY, ty)

pickTile(f, s, biome, tx, ty):
  e = s.elevation
  Ocean:
    e < VERY_DEEP_BELOW → VeryDeepWater;  e < DEEP_BELOW → DeepWater;  e < SHALLOW_BELOW → ShallowWater;  else Sand
  Mountain:
    eR = f.elevation(tx + 1, ty);  eD = f.elevation(tx, ty + 1)
    slope   = Math.max(Math.abs(eR - e), Math.abs(eD - e))
    k       = Math.floor(e * CLIFF_TERRACES)
    crosses = Math.floor(eR * CLIFF_TERRACES) !== k || Math.floor(eD * CLIFF_TERRACES) !== k
    slope >= CLIFF_SLOPE && crosses && f.detail(tx, ty) >= CLIFF_GAP_BELOW → Cliff;  else Stone
  River:
    s.riverDist >= s.riverHalfWidth → Sand                                   (bank)
    s.riverHalfWidth >= RIVER_DEEP_MIN_HALF_WIDTH
      && s.riverDist < s.riverHalfWidth - RIVER_SHALLOW_RIM
      && !isFord(f, tx, ty)                                                   → DeepWater
    else ShallowWater
  Forest:    f.detail(tx, ty) >= FOREST_DIRT_FROM    → Dirt;  else Grass
  Grassland: f.detail(tx, ty) >= GRASSLAND_DIRT_FROM → Dirt;  else Grass

generateChunk(seed, cx, cy):
  validate seed, cx, cy exactly as WLD-001 does (unchanged)
  f = createWorldFields(seed)
  for ly in 0..31, lx in 0..31:
    tx = cx * CHUNK_TILES + lx;  ty = cy * CHUNK_TILES + ly;  i = ly * CHUNK_TILES + lx
    s = sampleBiome(f, tx, ty);  b = classifyBiome(s)
    biomes[i] = b;  tiles[i] = pickTile(f, s, b, tx, ty)
  return { cx, cy, tiles, biomes }
```
Why these shapes (for the critic; do not re-decide):
- **Cliffs** are drawn where a steep slope crosses one of 25 elevation terraces, with gaps where `detail` is low. A plain slope threshold gives blobs of cliff, not ledges; terraces give 1-tile ledge lines that read as a 3/4 rock face (OQ-018). The slope and terrace test both use neighbour field values at world coordinates, so cliffs are seamless. WLD-004 makes them block; WLD-002 only places them.
- **River depth** follows the distance to the band centre (`riverDist`, in tiles). Water is deep only where the half-width is ≥ 4 tiles, and only ≥ 2 tiles in from each bank, so narrow rivers are entirely shallow (OQ-019: mostly shallow, deep only in wide stretches).
- **Fords** are a jittered stripe grid: in every 64-tile column cell and every 64-tile row cell there is one 3-tile stripe (seeded offset) where deep river water becomes shallow. Any deep stretch is therefore cut at least once per ~125 tiles along each axis it runs. This is a guarantee, not a probability. A noise-gated ford would not be.
- **River wins over Forest/Grassland but loses to Ocean and Mountain**, so rivers end at coasts and mountain feet. Continuous source-to-sea river topology is WLD-005.

   - Grassland, Forest, Mountain and Ocean are each ≥ 5 % [23.5, 32.1, 22.5, 19.8]. This catches a threshold or order bug that makes a biome vanish, e.g. the whole world turning into ocean.
   - Ocean ≤ 50 % and Mountain ≤ 50 % [19.8, 22.5]. With `OCEAN_BELOW` = 0.62, ocean is 77.5 %; with `MOUNTAIN_FROM` = 0.4, mountain is 75.7 %.
   - River is between 0.5 % and 10 % [2.07]. This catches a lost river band or a band unit error that floods the land.
   - Cliff is between 0.1 % and 3 % [0.53]. A slope threshold that is 10× off gives 0 %; wavelengths in chunks instead of tiles give 14.8 %.

   - `meanRun` is between 64 and 320 tiles (2–10 chunks) [143]. A run is a chord through a region, about half its diameter, and land regions measured 7–9 chunks across. Wavelengths 32× too small give 4 tiles; 4× too large give 417.

   It runs in about 0.5 s. To show it can fail, set `OCEAN_BELOW` to 0.62 and revert.
