     - Godot's JSON and `String.to_float` parsing isn't correctly rounded, so floats in fixtures travel as IEEE-754 hex bits;
     - `/` between two ints is integer division in GDScript (use `float()` or `floori(a / float(b))` deliberately);
     - int × int wraps at 64 bits, so `imul32` splits into 16-bit halves;
     - `.uid` sidecar files are committed with their scripts;
     - `godot --headless` can't render, so captures need xvfb (`capture.sh`), and software rendering runs at about 4 fps, which means captures prove looks, not fps;
     - the test runner fails a test on any `SCRIPT ERROR`/`ERROR:` output, a non-null return (including a stray `await`), or a file with zero tests;
     - cloud sessions install Godot via the SessionStart hook, so if `godot` is missing, check `/tmp/godot-setup.log`.

5. **Third-party credits and the check.**
   - **Location:** third-party files live under **`game/assets/third_party/`**. They must be inside the Godot project so `res://` can load them, which is why PLAN.md's `assets/` becomes this path. Record that in the D8 OQ row.
   - **Manifest:** `game/assets/third_party/CREDITS.md`. Its intro states the D8 rule in three lines, followed by one Markdown table with columns `Path | Source URL | Licence | Author | Changes`. `Path` is relative to `third_party/`.
   - **`tools/check-credits.sh`** (bash, no dependencies) exits non-zero with a clear message for each of:
     - a file under `third_party/` (excluding `CREDITS.md`, `*.import` and `*.uid`) with no table row;
     - a row whose file doesn't exist;
     - a licence not in the allow-list: `CC0-1.0`, `Public-Domain`, `MIT`, `Apache-2.0`, `BSD-2-Clause`, `BSD-3-Clause`, `CC-BY-3.0`, `CC-BY-4.0`, `OFL-1.1`, and share-alike `CC-BY-SA-3.0` / `CC-BY-SA-4.0` only when the Changes column contains "share-alike kept".
     - An empty `third_party/` with an empty table passes.
   - **CI:** add a step running it in `ci.yml`'s `godot` job, before the tests.
   - Don't add any third-party file in this task.
