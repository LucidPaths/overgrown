The GDD, `CLAUDE.md` and the agent docs describe overgrown the way Lucid now wants it:
- a desktop game for Lucid and a few friends, hosted on one machine;
- no phone, browser-link or viral-X target;

## Decisions (Lucid, 2026-10-13); apply exactly

### OQ-029: Platform and audience

overgrown is a **desktop game for Lucid and a few friends** (typically 2, up to ~4), not a public browser game.

- **Stack stays as is:** the TypeScript sim in a Web Worker, plus a web-tech client (Vite, WebGL), run as a desktop app. Which desktop shell (a local browser, Tauri or Electron) is decided by a later task. Until then the dev server or `vite preview` in a desktop browser is the way to play.
- **Reference machine:** Lucid's AMD Strix Halo (Radeon 8060S iGPU, 128 GB unified memory). The target is **60 fps at 1080p–1440p** with ~300 on-screen entities. A fast start matters, but there are **no download-size or slow-network budgets**: the ≤ 3 s slow-4G first frame and the ≤ 5 MB initial download are retired.
- **Phones are not a target.**
  - Touch input that already shipped (CMB-002, UIX-002) stays in the code but gets no further work.
  - Touch parts of open tasks are dropped. Keyboard, mouse and gamepad are the inputs.
- **Hosting:** one machine hosts the world (Lucid's machine, a server, or the dedicated host from TEC-018). Friends join over LAN or the internet (VPN or direct). There is no public link-sharing and no viral path. The transport is TEC-010's call; a signaling service is no longer required.
- **Identity:** a local profile name. Sign in with X is dropped, which supersedes OQ-004.
- **Saves:** stay local (world + character files). The storage technology is unchanged until a task needs otherwise.

### OQ-030: What "ours" means for assets

Every asset is **authored by us**, meaning Lucid or overgrown's Claude agents, by any method:
- procedural code at build time or runtime;
- hand-authored data files (models, animations, SVG, JSON);
- offline renders and baked textures.

Authored asset files **may be committed**.

Still **not allowed**:
- downloaded or third-party asset packs;
- traced or copied artwork;
- assets from outside image or audio services.

Libraries, engines and fonts used as tools are fine. Anything seeded still produces identical output for identical input. This supersedes the "generated by code / no AI-generated assets" wording.
