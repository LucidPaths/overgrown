# GOD-004: Worldgen port to GDScript (bit-for-bit with the TS worldgen)

Plan: `docs/overhaul/PLAN.md` § G0 ("**GOD-004** Worldgen port (noise, biomes, chunk generation, spawn search), with golden digests equal to the TypeScript output").
Milestone: G0   Depends on: GOD-003 (merged: `OgRng` in `game/src/core/rng.gd`)
Model: sonnet. The algorithms are fixed by the TS reference and the digests.
Branch: god-004-worldgen

## Desired result
`generate_chunk(seed, cx, cy)` in GDScript returns exactly the tiles and biomes that `generateChunk` returns in TS, and `find_spawn` returns the same spawn. This is proven by one shared fixture that both test suites check. After GOD-004 the TS worldgen can be retired (OVR-010) without losing a single world.

## Read these
- `sim/src/world/noise.ts`, `biome-map.ts`, `chunk-gen.ts`, `spawn.ts`, `walkability.ts`, `tile.ts`, `biome.ts`
- `sim/src/constants.ts`

## Locked design
1. **One shared fixture: `contracts/worldgen-vectors.json`.**
   - **What it holds:**
     - `chunks`: `[{seed, cx, cy, tilesDigest, biomesDigest}]`, the 10 cases currently in `chunk-gen.test.ts`, moved verbatim;
     - `spawn`: `[{seed, x, y}]` for seeds 0, 1, 2, 42 and 4294967295, computed by the TS `findSpawn` over a ground that generates chunks on demand;
     - `noise`: `[{seed, wavelengths, x, y, bits}]`, 8 samples of `createFbm`. Include negative and large coordinates. **`bits` is the float64 value's IEEE-754 bit pattern as a 16-digit hex string** (for example `"3fceaa…"`). Godot's JSON and `String.to_float` parsing is not correctly rounded (GOD-003 found a value read one ulp off), so floats must never travel through JSON as decimals. The TS side writes the bits with a `DataView`; the GDScript side compares `PackedByteArray.encode_double` bits, which is exact.
   - **Digest:** `deriveSeed(0, ...tiles)`, as in today's test.
   - **TS side:** `chunk-gen.test.ts` reads its digests from this file instead of inline literals. Add a TS test that checks the `spawn` and `noise` sections. This is the cross-language contract pattern of `rng-vectors.json`.
2. **GDScript files in `game/src/world/`** (`class_name` in brackets; the `Og` prefix avoids clashes with built-ins):
   - `tile.gd` (`OgTile`): the enums.
   - `biome.gd` (`OgBiome`): the enums.
   - `world_constants.gd` (`OgWorld`): `TILE_PX = 16`, `CHUNK_TILES = 32`.
   - `noise.gd` (`OgNoise`): `create_fbm(seed, wavelengths) -> Callable`, or a small `OgFbm` object with `sample(x, y)`, whichever reads better. Keep exactly the same operation order. Only `+ - * /`, `floor`, `abs`, `min` and `max`, with the same associativity as TS, because float results must match bit for bit.
   - `biome_map.gd`: world fields and `sample_biome` / `classify_biome`.
   - `chunk_gen.gd`: `generate_chunk(seed, cx, cy) -> {cx, cy, tiles: PackedByteArray(1024), biomes: PackedByteArray(1024)}`, plus `pick_tile` and `is_ford`.
   - `walkability.gd`: the `TILE_RULES` table.
   - `spawn.gd`: `find_spawn(seed)`. It uses an internal chunk cache to answer tile and biome lookups.
3. **Same validation as TS.** Out-of-range chunk coordinates and empty or invalid wavelengths call `push_error` and return an empty result. A test checks that.
4. **`game/tests/test_worldgen.gd`:**
   - Reads the fixture (same path pattern as `test_rng`). A missing file is a FAIL.
   - Checks every chunk digest, every spawn and every noise sample. Noise samples are compared by their exact float64 bit pattern, never approximately.
   - Checks that adjacent chunks share no seam: the border-tile equality the TS test does for one pair.
   - Reports the time for `generate_chunk` (median of 20). Information only; no threshold.
5. **Report for OVR-009** (don't edit `CLAUDE.md`): the contract rows "World tiles and chunk layout", "Worldgen noise", "Biome map", "Tile walkability" and "Spawn point" gain `game/src/world/*.gd` as a second implementation and `contracts/worldgen-vectors.json` as the shared check.

## Acceptance criteria
- **AC1** `bash tools/godot/test.sh` → all PASS, exit 0. The report gives the number of chunks, spawns and noise samples checked, plus the median `generate_chunk` time.
- **AC2** `npm test` → the TS suite passes, now reading the fixture. Prove the TS side can still fail: changing one digest in the JSON temporarily makes both the TS and the GDScript test FAIL; then revert.
- **AC3** Mutation: change `OCEAN_BELOW` in the GDScript port → the GDScript digests FAIL; revert.
- **AC4** `npm run check` → exit 0, with the venv activated on its own line first.
