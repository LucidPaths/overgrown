# ART-001: Asset pipeline scaffold → deterministic atlas PNG + JSON

GDD: docs/gdd/10-art-audio.md — "Pipeline scaffold: `build.py` → atlas PNG + JSON, consumed by the client (→ TEC-005)."
Milestone: M0   Depends on: OVR-001, OVR-002 (merged)
Model: opus — because the atlas JSON is a cross-language contract (Python writes it, the client reads it) and every future art generator plugs into this structure.
Branch: art-001-pipeline

## Desired result
`python3 tools/art/build.py` runs a fixed list of generators, packs their frames into `client/public/generated/core.png` + `core.json`, and produces byte-identical files on every run. The JSON is in the TexturePacker "JSON Hash" format that PixiJS v8's `Spritesheet` loads natively, so the client needs no custom parser.

## Locked design

Structure (all under `tools/art/`; it runs as a script, so `tools/art` is on `sys.path` and imports are `from lib.x import …`, `from gen import …`):
```
build.py            entry: ART_SEED = 1 (art is the same for every world); output dir default <repo>/client/public/generated (derived from __file__), --out overrides; logs one line per atlas
lib/atlas.py        Frame dataclass (name: str, image: PIL.Image RGBA) + pack() + write_atlas()
lib/context.py      Context(art_seed, generator_name).rng(*parts) -> Rng(derive_seed(art_seed, hash_string(generator_name), *parts))
gen/__init__.py     GENERATORS: list of generator modules, explicit (no discovery magic); each has NAME: str, ATLAS: str, generate(ctx) -> list[Frame]
gen/debug.py        NAME "debug", ATLAS "core"; frames below
tests/test_atlas.py
```

Frame rules: names match `^[a-z0-9_]+/[a-z0-9_/]+$` and start with `<generator NAME>/`. They must be unique across all generators; a duplicate raises naming both generators. Images must be RGBA.

`pack(frames, padding=1, max_size=2048)`: deterministic shelf packing. Sort by (-height, -width, name). The atlas is the smallest power-of-two square between 64 and 2048 that fits; raise with the total area and the largest frame if nothing fits. 1 px transparent padding between frames. No rotation, no trimming.

JSON (written with `json.dumps(obj, sort_keys=True, indent=1) + "\n"`):
```
{ "frames": { "<name>": { "frame": {"x","y","w","h"}, "rotated": false, "trimmed": false,
                          "spriteSourceSize": {"x":0,"y":0,"w","h"}, "sourceSize": {"w","h"} } },
  "meta": { "app": "overgrown-art", "version": "1", "image": "core.png", "format": "RGBA8888",
            "size": {"w","h"}, "scale": "1" } }
```
PNG: `image.save(path, format="PNG", compress_level=9)` with no metadata. Pillow writes no timestamp by default; keep it that way.

Debug generator frames (placeholder art, still generated by our code):
- `debug/checker16`: 16×16, 4×4-pixel checker in two greens.
- `debug/mover32`: 32×32, a filled circle (radius 12) with a 1 px darker outline. Its fill hue is picked with `ctx.rng("mover")`, so the RNG path through the pipeline is exercised. Pure Pillow/numpy drawing; no external images.

Delegated micro-decisions: exact colors; internal helper structure inside the listed files; CLI flag parsing (argparse).

## Acceptance criteria
- AC1 Build produces the atlas — proven by: `python3 tools/art/build.py` → `client/public/generated/core.png` and `core.json` exist; the JSON has frames `debug/checker16` and `debug/mover32`, and its sizes match the PNG.
- AC2 Determinism — proven by: build twice into two temp dirs (`--out`), then `cmp` both files → identical.
- AC3 Pixi can read it — proven by: `npm run build` copies `generated/core.json` + `core.png` into `client/dist/generated/`. Also the parsed JSON has exactly the keys Pixi's Spritesheet reads (frames.*.frame, meta.image, meta.size, meta.scale).
- AC4 Packing is correct — proven by: test that packs ~40 seeded random-size frames and asserts no two rectangles (with padding) overlap and all fit inside the atlas.
- AC5 Misuse is loud — proven by: tests for a duplicate frame name (the message names both generators) and an oversize frame set (raises).
- AC6 Green — `npm run check && npm test && npm run build` → exit 0.

## Tests
`tools/art/tests/test_atlas.py`: AC4 (overlap/bounds), AC5 (duplicate, oversize), plus one determinism test that runs the full build into two temp dirs and compares bytes. Each guards a silent failure: overlapping sprites, assets changing between builds, broken names. Show each fails when its guarded behaviour is broken, then revert.
