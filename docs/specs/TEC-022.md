## Locked design

### Which tick drives the animation
The animation clock is the **snapshot tick**, not interpolated render time: `elapsed = frame.tick - actionStart`, where `frame.tick` is `curr.tick`.
- `interpolate` already copies every discrete column (action, actionStart, facing, species) from `curr`, so the tick has to come from `curr` too.
- Elapsed is then an integer. ART-006's tables were derived on exactly this clock: attack shows 0,0,1,1,2,2,3,3 over `ATTACK_TICKS = 8`, and dodge shows 0,0,1,1,2,2,3 over `DODGE_TICKS = 7`.
- Fractional render time would only flip a frame up to one tick early. At 2–12 ticks per frame that adds nothing visible, but it would make one-shots cut their last frame short.
- Loop anims (idle, walk) also take their phase from `actionStart`. They are visual only, so no global clock is needed.

### `client/src/render/interpolate.ts`
`Frame` gains one field, placed after `count`:
```ts
  /** Tick of `curr`: the snapshot whose discrete columns (action, actionStart, facing, species) this frame shows. */
  tick: number;
```
`createFrame()` sets `tick: 0`. `interpolate()` sets `out.tick = curr.tick` next to `out.you = curr.you`. Nothing else in the file changes, and `interpolate.test.ts` stays unchanged.

### `client/src/render/actor-frames.ts` (new, pure: no Pixi, no DOM)
```ts
// Snapshot actor state → atlas frame name actor/<species>/<anim>/<dir>/<i> (TEC-022).
// Frame counts and timing come from ACTOR_ANIMS (ART-006); key strings are checked against contracts/actor-anims.json by the test.
import { Action, Facing, Species, type ActionValue, type FacingValue, type SpeciesValue } from "@overgrown/sim/protocol";
import { ACTOR_ANIMS, type ActorAnim, type ActorAnimTiming } from "./actor-anims";

const SPECIES_KEYS: Record<SpeciesValue, string> = {
  [Species.Human]: "human",
  [Species.Elf]: "elf",
  [Species.Dwarf]: "dwarf",
  [Species.Orc]: "orc",
  [Species.Foxfolk]: "foxfolk",
  [Species.Bearfolk]: "bearfolk",
  [Species.Rabbitfolk]: "rabbitfolk",
  [Species.Birdfolk]: "birdfolk",
  [Species.Lizardfolk]: "lizardfolk",
};

const DIR_KEYS: Record<FacingValue, string> = {
  [Facing.Down]: "down",
  [Facing.Left]: "left",
  [Facing.Right]: "right",
  [Facing.Up]: "up",
};

/** The animation each action plays. */
export const ACTION_ANIMS: Record<ActionValue, ActorAnim> = {
  [Action.Idle]: "idle",
  [Action.Walk]: "walk",
  // M1 has no weapons, so every attack is unarmed (OQ-022). This is the one switch point:
  // ART-009/CMB-007 pick the attack anim from the equipped weapon family (attack_blade, …) here.
  [Action.Attack]: "attack_unarmed",
  [Action.Dodge]: "dodge",
  [Action.Hurt]: "hurt",
  [Action.Death]: "death",
};

/**
 * Frame index `elapsed` ticks into an animation: i = floor(elapsed / ticksPerFrame); a loop shows i % frames,
 * a one-shot shows min(i, frames - 1) and holds its last frame. RangeError unless `elapsed` is an integer >= 0.
 */
export function animFrameIndex(timing: ActorAnimTiming, elapsed: number): number;

/**
 * The atlas frame for one character at snapshot `tick`. The arguments are raw snapshot column values.
 * RangeError naming the field and its value if species, facing or action is not in its enum,
 * or if actionStart is after tick.
 */
export function actorFrame(species: number, facing: number, action: number, actionStart: number, tick: number): string;
//   = `actor/${SPECIES_KEYS[species]}/${anim}/${DIR_KEYS[facing]}/${animFrameIndex(ACTOR_ANIMS[anim], tick - actionStart)}`
//     with anim = ACTION_ANIMS[action]

/** Every name actorFrame can return: species × dirs × each anim in ACTION_ANIMS (deduplicated) × its frames. */
export function actorFrameNames(): string[];
```
- The lookups of runtime numbers use the existing pattern from `snapshot-view.ts`: `(TABLE as Record<number, T | undefined>)[value]`, followed by a throw when the result is undefined. One private helper serves all three tables.
- The tables are `Record<…Value, …>`, so adding an enum member without a key fails typecheck. `ActorAnim` makes `ACTION_ANIMS` reject an anim name that `ACTOR_ANIMS` lacks.
- No caching or precomputed texture grid. `actorFrame` builds one short string per character per frame, which is negligible at M1 counts (Simplicity Wins).

### `client/src/render/kind-frames.ts`
`KIND_FRAMES` stops being one static name per Kind and becomes a per-row frame resolver. It stays tsc-enforced. `requireFrames` is unchanged.
```ts
// Which atlas frame draws each sim Kind, per entity row of an interpolated Frame. Adding a Kind without an entry fails typecheck.
export const KIND_FRAMES: Record<KindValue, (frame: Frame, i: number) => string> = {
  [Kind.Character]: (f, i) => actorFrame(f.species[i]!, f.facing[i]!, f.action[i]!, f.actionStart[i]!, f.tick),
};
```

### `client/src/render/snapshot-view.ts`: the locked Pixi approach
- `textureFor(kind)` becomes `textureFor(s: Frame, i: number): Texture`:
  - It looks up `KIND_FRAMES[s.kind[i]]`. If there is no entry, it throws the existing "no atlas frame is assigned to entity kind …" error.
  - It calls the resolver to get the name and returns `this.sheet.textures[name]`. If that is undefined, it throws `atlas frame "<name>" (entity <id>, kind <kind>) is missing from the core atlas`.
- In `update`, the texture is resolved for every row on every call. A new sprite is `new Sprite(texture)` with the existing `anchor.set(0.5, 1)`. An existing sprite gets `sprite.texture = texture`.
- Every texture is one the `Spritesheet` already built. Nothing calls `new Texture`, `Texture.from` or anything else that allocates. Pixi 8.22's `Sprite.texture` setter returns early when given the same texture, so steady frames cost one map lookup and no GPU work.
- Do not use `AnimatedSprite`. It runs its own clock and would ignore the sim's `actionStart`.
- Every actor frame is 32×32 with anchor (0.5, 1), so the "sprites snap to whole art pixels" trap holds. `Math.round` positions stay as they are.

## Tests
`client/src/render/actor-frames.test.ts` (new). It imports `fixture from "../../../contracts/actor-anims.json"` the way `actor-anims.test.ts` does. It has three tests:

1. **"every name actorFrame returns is a contract frame, and every mapped frame is reached"**
   - Contract set: `actor/{s}/{a}/{d}/{i}` for every s in `fixture.species`, every d in `fixture.dirs`, every (a, n) in `fixture.frames` and every i in `0..n-1`.
   - Sweep: every value of `Species`, `Facing` and `Action` (via `Object.values`), with `actionStart = 5` and `tick = 5 + e` for every e in `0..99`. Collect the names into a Set.
   - Assert the list of swept names missing from the contract set equals `[]`.
   - Assert the sorted swept set equals the sorted `actorFrameNames()`.
   - Guards: a wrong species or dir key, an anim name the pipeline doesn't draw, or an off-by-one frame index. Any of these is otherwise only a runtime missing texture for one species, facing or moment of an action. It also guards a frame that is never shown, and `actorFrameNames()` (the load check) drifting from what is actually drawn.
2. **"frame index: loops wrap, one-shots clamp to and hold the last frame"**
   - Use literal timings, not `ACTOR_ANIMS`, so tuning never breaks the test.
   - `animFrameIndex({frames: 4, ticksPerFrame: 3, loop: true}, e)` for e = 0..12 gives `[0,0,0,1,1,1,2,2,2,3,3,3,0]`.
   - `animFrameIndex({frames: 4, ticksPerFrame: 2, loop: false}, e)` for e = 0..9 gives `[0,0,1,1,2,2,3,3,3,3]`, and e = 1e6 gives 3.
   - `animFrameIndex(…, -1)` and `animFrameIndex(…, 1.5)` throw RangeError.
   - `actorFrame(Species.Foxfolk, Facing.Right, Action.Death, 100, 100_100)` equals `` `actor/foxfolk/death/right/${ACTOR_ANIMS.death.frames - 1}` ``.
   - `actorFrame(Species.Human, Facing.Down, Action.Idle, 10, 9)` throws RangeError.
   - Guards: a one-shot that loops (an attack replaying mid-swing) and a loop that freezes. Both are silent at a glance in a still screenshot.
3. **"attack and dodge reach their last frame within the sim's action duration"**
   - For `[Action.Attack, ATTACK_TICKS]` and `[Action.Dodge, DODGE_TICKS]` (from `@overgrown/sim/actions`), with `t = ACTOR_ANIMS[ACTION_ANIMS[action]]`, assert `(t.frames - 1) * t.ticksPerFrame < duration`.
   - This is the invariant ART-006 handed to TEC-022. Snapshots `s .. s+D-1` show the action (CMB-001), so the last frame shows at least one tick.
   - Guards: tuning a sim duration or an anim timing so the last frame is silently never drawn. It uses `ACTION_ANIMS`, so it still holds once ART-009 switches the attack to `attack_blade`.

No test for `snapshot-view.ts`, `kind-frames.ts` or `main.ts`. That is Pixi wiring, covered by AC5–AC7 and the M1 E2E. No `interpolate.test.ts` change: if `Frame.tick` were wrong, `actorFrame` would throw (actionStart after tick) or show the wrong frame, and AC5 catches both.

// TEC-022 scripted animation check. Run from the repo root: node --input-type=module < /tmp/tec022-anim.mjs
import { chromium } from "playwright-core";

const URL = "http://localhost:4201/";
// 1280×720 at DPR 1 → camera scale 2 with the `you` feet at device (640, 360): the 32×32 frame covers this rect.
const SPRITE = { x: 608, y: 296, width: 64, height: 64 };
const errors = [];

// Runs in the page before app code: records the `you` row of each snapshot.
function instrument() {
  const Base = window.Worker;
  window.__you = null;
  window.Worker = class extends Base {
    constructor(...args) {
      super(...args);
      this.addEventListener("message", (e) => {
        const s = e.data && e.data.snapshot;
        if (!s) return;
        const i = s.ids.indexOf(s.you);
        if (i >= 0) {
          window.__you = { tick: s.tick, x: s.x[i], y: s.y[i], facing: s.facing[i], action: s.action[i], actionStart: s.actionStart[i] };
        }
      });
    }
  };
}

const browser = await chromium.launch();
const r = {};
let idleShot = null;
let attackShot = null;
try {
  const page = await browser.newPage({ viewport: { width: 1280, height: 720 } });
  page.on("pageerror", (e) => errors.push(`pageerror: ${e.message}`));
  page.on("console", (m) => { if (m.type() === "error") errors.push(`console: ${m.text()}`); });
  await page.addInitScript(instrument);
  await page.goto(URL);
  await page.waitForFunction(() => window.__you !== null, null, { timeout: 5000 });
  const you = () => page.evaluate(() => window.__you);
  const waitAction = (a) => page.waitForFunction((a) => window.__you.action === a, a, { timeout: 3000 });
  // Let chunk streaming around spawn finish, so no ground re-bake lands between the two compared shots.
  await page.waitForTimeout(1500);

  // Walk right; a view-only shot mid-walk (ground may scroll under it, so it is not compared).
  await page.keyboard.down("KeyD");
  await page.waitForTimeout(600);
  const w0 = await you();
  await page.screenshot({ path: "/tmp/tec022-walk.png", clip: SPRITE });
  const w1 = await you();
  await page.keyboard.up("KeyD");
  r.walk = { before: w0, after: w1 };
  await waitAction(0);

  // Aim right of the character: the attack keeps facing Right, and the rooted attack keeps the camera still,
  // so between the idle and attack shots only the sprite can change.
  await page.mouse.move(840, 328);
  await page.waitForTimeout(200);
  const i0 = await you();
  idleShot = await page.screenshot({ path: "/tmp/tec022-idle.png", clip: SPRITE });
  const i1 = await you();
  r.idle = { before: i0, after: i1 };

  // An attack lasts 8 ticks (0.4 s); retry if the shot did not land inside a single attack.
  for (let t = 1; t <= 5 && attackShot === null; t++) {
    r.attackTries = t;
    await waitAction(0);
    const prevStart = (await you()).actionStart;
    await page.mouse.down();
    await page.mouse.up();
    await page.waitForFunction((s) => window.__you.action === 2 && window.__you.actionStart !== s, prevStart, { timeout: 3000 });
    const a0 = await you();
    const shot = await page.screenshot({ path: "/tmp/tec022-attack.png", clip: SPRITE });
    const a1 = await you();
    r.attack = { before: a0, after: a1 };
    if (a1.action === 2 && a1.actionStart === a0.actionStart) attackShot = shot;
  }

  // Dodge once, so the dodge frames are looked up too (a missing frame is a page error).
  await waitAction(0);
  await page.keyboard.press("Space");
  await waitAction(3);
  await waitAction(0);
  r.dodged = true;
} finally {
  await browser.close();
}

const same = (a, b) => a.x === b.x && a.y === b.y;
const { walk, idle, attack } = r;
const checks = {
  walked: walk.before.action === 1 && walk.after.action === 1 && walk.after.facing === 2 && walk.after.x > walk.before.x,
  idleShot: idle.before.action === 0 && idle.after.action === 0 && idle.after.facing === 2 && same(idle.before, idle.after),
  attackShot: attackShot !== null && attack.after.facing === 2 && same(idle.after, attack.before) && same(attack.before, attack.after),
  differentFrame: attackShot !== null && idleShot !== null && !idleShot.equals(attackShot),
  dodged: r.dodged === true,
  noErrors: errors.length === 0,
};
console.log(JSON.stringify({ checks, results: r, errors }, null, 2));
process.exitCode = Object.values(checks).every(Boolean) ? 0 : 1;
EOF
node --input-type=module < /tmp/tec022-anim.mjs; echo "exit=$?"
pkill -f "[v]ite preview --port 4201" || true
