# TEC-002: Sim runs in a Web Worker; snapshot protocol to the renderer

GDD: docs/gdd/01-tech.md — "Sim runs in a Web Worker; snapshot message protocol to the renderer."
Milestone: M0   Depends on: TEC-001, TEC-004, OVR-002 (merged)
Model: opus — because the sim↔renderer protocol is a core contract, and the sim must stay runnable in Node for dedicated hosts.
Branch: tec-002-sim-worker

## Desired result
The client starts the simulation in a Web Worker. The sim (pure, browser-free) owns an ECS world with 64 deterministic "debug movers", steps it 20 times a second, and posts snapshots as transferable typed arrays. The renderer draws whatever the latest snapshot says and never touches sim state. The same sim code runs under Node in tests.

## Locked design

Sim package (browser-free; lib ES2022, types []):
- `sim/src/constants.ts`: `export const TICK_HZ = 20; export const TICK_MS = 1000 / TICK_HZ;`
- `sim/src/protocol.ts`: the single source of truth for messages.
  ```ts
  export type HostToSim = { type: "init"; seed: number };
  export interface Snapshot { tick: number; count: number; ids: Uint32Array; x: Float32Array; y: Float32Array; kind: Uint16Array }
  export type SimToHost = { type: "snapshot"; snapshot: Snapshot } | { type: "error"; message: string };
  export const Kind = { DebugMover: 1 } as const;
  export function snapshotBuffers(s: Snapshot): ArrayBuffer[]   // the transfer list
  ```
- `sim/src/debug-movers.ts`: `spawnDebugMovers(world, components, rng, n = 64)` places movers at random positions in a 640×360 area with random velocities (20–60 px/s, random direction); `stepDebugMovers(world, components, dt)` integrates position and bounces off the area edges. Temporary scaffolding, replaced by real entities in M1/M2.
- `sim/src/sim.ts`: `export function createSim(seed: number): Sim` where `Sim = { readonly tick: number; step(): void; snapshot(): Snapshot }`. Registers components Position {x,y: f32}, Velocity {vx,vy: f32}, Kind {kind: u16}. Movers use `new Rng(deriveSeed(seed, hashString("debug-movers")))`. `step()` advances exactly one tick (dt = 1/TICK_HZ). `snapshot()` returns fresh typed arrays (length = count), filled via `world.each`.
- Do NOT modify ecs.ts or rng.ts; use their public APIs.

Client:
- `client/src/sim-worker.ts`: a thin adapter, the only place that touches worker globals. On `init`: `createSim(seed)`, then a `setInterval(TICK_MS)` loop that calls `step()` and posts the snapshot with its buffers transferred. TEC-003 will replace this loop with a fixed-timestep accumulator. Any thrown error is posted as `{ type: "error" }` and `console.error`ed.
- `client/src/render/snapshot-view.ts`: `class SnapshotView { constructor(parent: Container); update(s: Snapshot): void }`. Keeps `Map<id, Sprite>`; creates `Sprite(Texture.WHITE)` 8×8 for new ids (tint by kind), removes sprites whose ids vanished, and sets positions from the snapshot. Read-only toward the sim.
- `client/src/main.ts`: after Pixi init, read the `seed` from the URL (`?seed=<int>`, default 1, invalid → default plus a console.warn), start the worker with `new Worker(new URL("./sim-worker.ts", import.meta.url), { type: "module" })`, post `init`, and on each snapshot call `view.update`. On an `error` message, show it with the same DOM error display as a renderer failure (reuse it; don't duplicate).
- No `any`. If worker globals need typing, keep it local to sim-worker.ts; don't add a second tsconfig unless typecheck truly can't work without it (then explain why in the report).

## Acceptance criteria
- AC1 Determinism in Node — proven by: test "two sims with the same seed produce identical snapshots after 100 steps" and test "different seeds produce different snapshots".
- AC2 Sim is browser-free — proven by: `npm run check` → exit 0 with sim/tsconfig unchanged (lib ES2022, types []).
- AC3 Movers render and move — proven by: `npm run build`, preview on port 4176, `check.mjs` → canvas true, errors []. Two screenshots ~1 s apart show 64 small squares that have moved.
- AC4 Buffers are transferred, not copied — proven by: in the worker, after `postMessage`, the snapshot's `ids.byteLength === 0` (detached). Check it once with a temporary console.log or a debugger, then remove it.
- AC5 Worker errors surface — proven by: temporarily throwing inside `step()`, rebuilding and running check.mjs → the page shows the error text; revert.
- AC6 Green — `npm run check && npm test && npm run build` → exit 0.

## Tests
`sim/src/sim.test.ts` with exactly the two AC1 tests. They guard determinism, and that the seed actually reaches the sim. Show each fails when broken (e.g. use a constant instead of the seed), then revert.
