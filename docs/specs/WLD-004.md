# WLD-004: Tile walkability, foot-box collision and the spawn search

GDD: docs/gdd/02-world.md — "**WLD-004** `[proto]` Tile collision and walkability; water depth layer; cliff tiles block, shallow water slows, deep water blocks (OQ-018, OQ-019); collider per OQ-025."

Model: sonnet — because the design is fully locked below (one table, one pure collision function, one ring search); the risks are off-by-one tile edges and axis order, and the tests pin both.
Branch: wld-004-collision

## Desired result
Every character (player or NPC, in every action: walk, sprint, dodge) moves through the same collision rule: its 10×6 px foot box cannot enter Cliff, DeepWater or VeryDeepWater tiles, slides along them axis by axis, and moves at ×0.6 while its box centre is over ShallowWater. One `Record<TileValue, …>` table holds walkability, speed factor and water depth for every tile. `createSim` places the player on the nearest walkable Grassland tile to (0, 0) instead of at (0, 0), or throws if none lies within the search radius.

### Walkability table (`sim/src/world/walkability.ts`, new)
```ts
import { Tile, type TileValue } from "./tile";

/** (tx, ty) → tile. ChunkStore.tileAt satisfies it. */
export type TileLookup = (tx: number, ty: number) => TileValue;

export interface TileRule {
  /** Can a foot box enter this tile? */
  readonly walkable: boolean;
  /** Multiplies displacement while the box centre is over this tile. */
  readonly speed: number;
  /** Water depth layer: dry 0, shallow 1, deep 2, very deep 3. Derived from the tile; there is no second array (M1 contracts). */
  readonly depth: 0 | 1 | 2 | 3;
}

export const SHALLOW_WATER_SPEED = 0.6; // OQ-019, tunable

/** The one walkability rule set (OQ-018, OQ-019). tsc enforces an entry per Tile. */
export const TILE_RULES: Readonly<Record<TileValue, TileRule>> = {
  [Tile.Grass]:         { walkable: true,  speed: 1, depth: 0 },
  [Tile.Dirt]:          { walkable: true,  speed: 1, depth: 0 },
  [Tile.Sand]:          { walkable: true,  speed: 1, depth: 0 },
  [Tile.Stone]:         { walkable: true,  speed: 1, depth: 0 },
  [Tile.Cliff]:         { walkable: false, speed: 1, depth: 0 },
  [Tile.ShallowWater]:  { walkable: true,  speed: SHALLOW_WATER_SPEED, depth: 1 },
  [Tile.DeepWater]:     { walkable: false, speed: 1, depth: 2 },
  [Tile.VeryDeepWater]: { walkable: false, speed: 1, depth: 3 },
};
```
`speed` of a blocked tile is 1 (comment says so): the centre can only be over one if the character was placed overlapping it, and it must be able to walk out at normal pace. No `waterDepth()` helper (no consumer yet; read `TILE_RULES[t].depth`).

### Collision (`sim/src/world/collision.ts`, new; inside the worldgen ESLint block)
The foot box of a character at feet point (x, y) with Collider (hw, hh) is the **half-open** span `[x − hw, x + hw) × [y − 2·hh, y)`. A box whose edge lies exactly on a tile border does not touch the tile beyond it. Only `+ - * /`, `Math.floor/abs/min/max`, comparisons.
```ts
/** First tile index a half-open span [a, b) touches: Math.floor(a / TILE_PX). */
/** Last tile index it touches: -Math.floor(-b / TILE_PX) - 1 (ceil without Math.ceil). */

/** Moves the box by (dx, dy): x first (at the old y), then y (at the new x). Returns the new feet point. */
export function slideMove(tileAt: TileLookup, x: number, y: number, hw: number, hh: number, dx: number, dy: number): { x: number; y: number };

/** TILE_RULES[tile under the box centre (x, y − hh)].speed */
export function speedFactorAt(tileAt: TileLookup, x: number, y: number, hh: number): number;
```
Algorithm (locked):
```
blocked(tx, ty) = !TILE_RULES[tileAt(tx, ty)].walkable

resolveX(x, y, dx):                          rows = first(y − 2hh) .. last(y)
  dx > 0: for col = last(x + hw) + 1 up to last(x + dx + hw):    if any row blocked(col, row) → return col·TILE_PX − hw
  dx < 0: for col = first(x − hw) − 1 down to first(x + dx − hw): if any row blocked → return (col + 1)·TILE_PX + hw
  return x + dx                              (dx = 0 → x, no lookups)

resolveY(x, y, dy):                          cols = first(x − hw) .. last(x + hw)
  dy > 0: for row = last(y) + 1 up to last(y + dy):              if any col blocked(col, row) → return row·TILE_PX
  dy < 0: for row = first(y − 2hh) − 1 down to first(y + dy − 2hh): if any blocked → return (row + 1)·TILE_PX + 2hh
  return y + dy

slideMove: nx = resolveX(x, y, dx); ny = resolveY(nx, y, dy); return { x: nx, y: ny }
```
Consequences (locked, for the critic):
- **Every column/row the box newly enters is scanned, nearest first**, so no speed can tunnel through a 1-tile wall.
- **Only newly entered tiles are checked.** A box already overlapping a blocked tile is never pushed out and can walk out. Nothing in M1 places a box there (`findSpawn` puts it inside one walkable tile).
- **Sliding is per axis, without redistribution:** a diagonal into a wall keeps only its free component, so you slide along the wall at that component's speed.
- **Axis order is x then y.** At an outside corner, a diagonal step that is free in x alone moves in x and stops flush in y.
- The clamped coordinate is exact (`col·16 − 5` etc. are small integers), so a flush box stays flush: the next step's scan starts at the blocked column and returns the same value.
- **Characters don't collide with each other** (OQ-025): collision reads tiles only.

### Movement (`sim/src/movement.ts`, extended)
- Signature: `stepMovement(world: CharacterWorld, tick: number, tileAt: TileLookup): void`. Required, no default: there is no "no ground" mode.
- The `each` query adds `collider`. hw/hh come from the Collider component, never from `FOOT_HALF_W/H`.
- Both branches that move (Dodge, and Idle/Walk) replace `x += v/TICK_HZ; y += …` with one shared step:
  ```
  f = speedFactorAt(tileAt, x[i], y[i], hh[i])          // sampled before the move
  p = slideMove(tileAt, x[i], y[i], hw[i], hh[i], vx * f / TICK_HZ, vy * f / TICK_HZ)
  x[i] = p.x; y[i] = p.y
  ```
  For f = 1 this is bit-identical to today (`v * 1 / 20 === v / 20`), so CHR-001/CMB-001 assertions stay exact on open ground.
- **Velocity is unchanged:** it stays the requested velocity (intent × speed, or the dodge velocity `stepActions` set). The factor and the wall act on displacement only. Multiplying the stored dodge velocity would compound (0.6⁷).
- The Attack branch (rooted) is unchanged. Facing and the Walk/Idle action still follow the requested velocity: pushing into a wall plays Walk. A dodge into a wall stays Dodge for its full `DODGE_TICKS`.
- One rule: no player check, no per-action exception. The shallow factor applies to walk, sprint and dodge alike (a roll through shallow water covers 28.8 px).
- Header comment: keep the arithmetic note, add that collision and the speed factor live in `world/collision.ts` (lint-enforced).

### Spawn search (`sim/src/world/spawn.ts`, new; inside the worldgen ESLint block)
```ts
export const SPAWN_SEARCH_RADIUS = 256; // tiles, Chebyshev, around tile (0, 0); tunable. Max seen over seeds 0–199: 163.

export interface SpawnGround {
  tileAt(tx: number, ty: number): TileValue;
  biomeAt(tx: number, ty: number): BiomeValue;
}

/**
 * OQ-024: the feet point (tx·TILE_PX + 8, ty·TILE_PX + 8) at the centre of the nearest tile whose biome is Grassland
 * and whose tile is walkable. "Nearest": the smallest Chebyshev ring r = max(|tx|, |ty|) = 0, 1, … SPAWN_SEARCH_RADIUS
 * that contains any such tile; within that ring, the smallest (tx² + ty², ty, tx). The result doesn't depend on loop order.
 * Throws Error("findSpawn: no walkable Grassland tile within 256 tiles (Chebyshev) of tile (0, 0)") — wording with the
 * constant interpolated — if no ring up to the radius has one. Never falls back to (0, 0).
 */
export function findSpawn(ground: SpawnGround): { x: number; y: number };
```
At the centre feet point the box `[3, 13) × [2, 8)` (tile-local) lies inside that tile, and so does the speed sample point.
