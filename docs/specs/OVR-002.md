## Locked design

All arithmetic is unsigned 32-bit. In TS use `Math.imul`, `>>>` and `| 0`; in Python mask with `& 0xFFFFFFFF` after every add, multiply and shift-left.

```
fmix32(x):                         # murmur3 finalizer
  x ^= x >>> 16; x = imul(x, 0x85ebca6b)
  x ^= x >>> 13; x = imul(x, 0xc2b2ae35)
  x ^= x >>> 16; return x >>> 0

splitmix32 step(state) -> (state', out):
  state' = (state + 0x9e3779b9) mod 2^32
  z = state'
  z = imul(z ^ (z >>> 16), 0x85ebca6b)
  z = imul(z ^ (z >>> 13), 0xc2b2ae35)
  out = (z ^ (z >>> 16)) >>> 0

Rng(seed):                         # seed: integer 0..2^32-1, else throw
  s = seed; (s, a) = splitmix32(s); (s, b) = splitmix32(s); (s, c) = splitmix32(s); (s, d) = splitmix32(s)
  then discard 12 outputs of nextU32()

nextU32():                         # sfc32
  t = (a + b + d) mod 2^32
  d = (d + 1) mod 2^32
  a = b ^ (b >>> 9)
  b = (c + (c << 3)) mod 2^32
  c = rotl32(c, 21)
  c = (c + t) mod 2^32
  return t

nextFloat(): nextU32() / 4294967296        # [0, 1), exact in float64 in both languages
int(lo, hi): lo + floor(nextFloat() * (hi - lo + 1))
  # inclusive; lo, hi must be integers with lo <= hi and hi - lo < 2^32, else throw

deriveSeed(seed, ...parts):        # sub-seeds, e.g. (worldSeed, chunkX, chunkY)
  h = fmix32(seed)                 # seed: 0..2^32-1 integer, else throw
  for p in parts:                  # p: any integer in the signed or unsigned 32-bit range, else throw
    u = p mod 2^32                 # two's complement: -1 -> 0xFFFFFFFF
    h = (fmix32(h ^ fmix32(u)) + 0x9e3779b9) mod 2^32
  return h

hashString(s):                     # namespaces, e.g. generator or species names
  FNV-1a 32 over the UTF-8 bytes of s (offset 0x811c9dc5, prime 0x01000193), then fmix32 of the result
```

API names:
- TS `sim/src/rng.ts`: `export class Rng { constructor(seed: number); nextU32(): number; nextFloat(): number; int(lo: number, hi: number): number }`, `export function deriveSeed(seed: number, ...parts: number[]): number`, `export function hashString(s: string): number`. UTF-8 bytes via `TextEncoder` (it's in ES2022 lib? if not available under lib ES2022 + types [], implement UTF-8 encoding by hand — do NOT add DOM types to sim).
- Python `tools/art/lib/rng.py` (create `tools/art/lib/__init__.py`, empty): `class Rng: __init__(seed); next_u32(); next_float(); int(lo, hi)`, `derive_seed(seed, *parts)`, `hash_string(s)`.
- Errors: invalid arguments throw / raise with an actionable message naming the argument and the value.

Contract file `contracts/rng-vectors.json`, generated once from the TS implementation and committed:
```
{
  "algorithm": "sfc32 seeded by splitmix32, 12 discards; deriveSeed fmix32-combine; hashString fnv1a32+fmix32",
  "rng": [ { "seed": <n>, "u32": [first 10 nextU32] } ... ]   for seeds 0, 1, 42, 2147483647, 4294967295
  "float": { "seed": 42, "values": [first 5 nextFloat] },
  "int": { "seed": 42, "lo": 1, "hi": 6, "values": [first 20 int(1,6)] },
  "derive": [ { "seed": 42, "parts": [], "out": n }, { "seed": 42, "parts": [0,0] }, { "seed": 42, "parts": [1,0] },

```
(every entry gets its `out`.)

Tests (both read the same JSON; TS via a JSON import with `resolveJsonModule` in sim/tsconfig.json — no Node types in sim):
- `sim/src/rng.test.ts` asserts every vector.
- `tools/art/tests/test_rng.py` asserts every vector (locate the file relative to `__file__`).
- Plus in both: `int()` rejects lo > hi and non-integers (guards the clamp/rounding edge that would otherwise silently skew rolls).

Delegated micro-decisions: internal helper names; how the vectors were generated (a throwaway script outside the repo is fine, don't commit it).
