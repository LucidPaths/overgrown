# overgrown

An open-source, browser-first, top-down sandbox hack-and-slash RPG.

A cozy, saturated world where you are *just another one*: NPCs live, learn, trade, migrate and die by the same rules you do. Monsters age, breed and take over land if nobody pushes back. Wander too far, or let an area grow wild, and the lovely world turns into hell difficulty.

- **Plays in a browser tab**, desktop and phone (touch from day one), launched straight from a shared link.
- **Host-in-your-tab multiplayer**: solo is just a world nobody has joined yet. Open it to friends and up to 10 players join peer-to-peer.
- **Every asset is ours**: sprites, tiles, effects and audio are all generated by code in this repo.

## Status

Pre-production. The design lives in [`docs/gdd/`](docs/gdd/README.md). Every task in the GDD has a stable ID; when a PR implements one, the box gets ticked and the PR gets linked next to it. See [the workflow](docs/gdd/README.md#workflow).
