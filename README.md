# overgrown

An open-source, desktop, top-down sandbox hack-and-slash RPG for you and a few friends (OQ-029).

A cozy, saturated world where you are *just another one*: NPCs live, learn, trade, migrate and die by the same rules you do. Monsters age, breed and take over land if nobody pushes back. Wander too far, or let an area grow wild, and the lovely world turns into hell difficulty.

- **A desktop game for a few friends** (typically 2, up to ~4): no phone or browser-link target, no accounts (OQ-029).
- **One-machine-hosts multiplayer**: solo is just a world nobody has joined yet. Open it to friends and they join the host over LAN or the internet.
- **Every asset is ours**: sprites, tiles, effects and audio are all authored by us (Lucid or the project's Claude agents), by any method, never downloaded or third-party (OQ-030).

## Status

Pre-production. The design lives in [`docs/gdd/`](docs/gdd/README.md). Every task in the GDD has a stable ID; when a PR implements one, the box gets ticked and the PR gets linked next to it. See [the workflow](docs/gdd/README.md#workflow).
